2.1. Условия минимума и методы безусловной минимизации

Вопрос / терминОпределение, смысл и пример
МинимизацияПоиск таких значений переменных, при которых целевая функция принимает наименьшее значение. Целью может быть стоимость, ошибка, время или расход ресурсов. Пример: подобрать температуру и скорость станка так, чтобы брак был минимальным.
Для понимания: Сначала формулируют, что именно уменьшают, затем находят допустимые значения переменных и сравнивают значения функции.
Безусловная минимизацияЗадача вида f(x) → min, где дополнительных ограничений на переменные нет, кроме области определения самой функции. Пример: найти минимум функции (x − 3)² на всей числовой прямой.
Для понимания: Не путай с условной оптимизацией: там появляются равенства или неравенства вроде x + y ≤ 10.
Локальный минимумТочка, в которой значение функции не больше значений во всех достаточно близких точках. Пример: ближайшая низина в холмистой местности.
Для понимания: Локальный минимум лучший только в своей окрестности; где-то далеко может существовать более глубокая впадина.
Глобальный минимумТочка с наименьшим значением функции среди всех рассматриваемых точек. Пример: самая глубокая низина на всей карте.
Для понимания: В выпуклой задаче любой локальный минимум автоматически является глобальным, но в обычной невыпуклой задаче это не гарантируется.
Гладкая функцияФункция, у которой существуют и достаточно хорошо ведут себя нужные производные. Для условий первого порядка нужна первая производная, для условий второго порядка — вторые производные.
Для понимания: Слово «гладкая» здесь означает, что функцию можно исследовать через её наклон и кривизну.
Необходимое условиеУсловие, которое обязательно выполняется в точке минимума, но само по себе ещё не доказывает минимум. Для внутренней точки одной переменной: f′(x*) = 0.
Для понимания: Нулевая производная бывает и в максимуме, и в точке перегиба, поэтому это только поиск кандидата.
Достаточное условие для одной переменнойЕсли f′(x*) = 0 и f″(x*) > 0, то точка является строгим локальным минимумом. При f″(x*) < 0 получается максимум.
Для понимания: Вторая производная показывает кривизну: положительная кривизна означает форму чаши, отрицательная — форму холма.
Если вторая производная равна нулюУсловие второго порядка не даёт ответа. Нужно исследовать производные более высокого порядка, знак первой производной или поведение функции рядом с точкой. Пример: f(x)=x⁴ имеет минимум при x=0, хотя f″(0)=0.
Для понимания: Ноль во второй производной — это не отсутствие минимума, а недостаток информации.
ГрадиентВектор всех первых частных производных: ∇f=(∂f/∂x₁,…,∂f/∂xₙ). Он показывает направление самого быстрого роста функции.
Для понимания: Чтобы уменьшать функцию, обычно движутся в противоположную сторону — по антиградиенту.
Стационарная точкаТочка, в которой градиент равен нулю: ∇f(x*)=0. Это необходимое условие внутреннего минимума гладкой функции нескольких переменных.
Для понимания: Стационарная точка является только кандидатом: она может оказаться минимумом, максимумом или седловой точкой.
Матрица ГессеМатрица всех вторых частных производных функции. Она описывает кривизну поверхности по разным направлениям.
Для понимания: Градиент отвечает за наклон, а Гессе — за то, как этот наклон изменяется.
Положительно определённый ГессеЕсли в стационарной точке матрица Гессе положительно определена, то функция изгибается вверх по всем направлениям и точка является строгим локальным минимумом.
Для понимания: Для функции двух переменных часто проверяют положительность первого главного минора и определителя Гессе.
Седловая точкаСтационарная точка, где по одним направлениям функция возрастает, а по другим убывает. Пример: поверхность седла лошади.
Для понимания: Если Гессе неопределён, то стационарная точка обычно является седловой, а не минимумом.
Методы нулевого порядкаЧисленные методы, использующие только значения функции, без производных. Примеры: перебор, дихотомия, золотое сечение, случайный поиск.
Для понимания: Подходят, когда функция задана экспериментом или программой, но обычно требуют больше вычислений функции.
Метод золотого сеченияОдномерный метод, который последовательно сужает интервал, содержащий минимум, сохраняя специальное отношение длин частей. Применяется для унимодальной функции на отрезке.
Для понимания: Унимодальность означает, что на выбранном отрезке функция сначала убывает, затем возрастает и имеет один минимум.
Методы первого порядкаИспользуют первые производные. Основной представитель — градиентный спуск, где новая точка получается движением против градиента.
Для понимания: Они быстрее методов без производных, но качество работы сильно зависит от выбора шага и формы поверхности.
Градиентный спускИтерация: xᵏ⁺¹ = xᵏ − αₖ∇f(xᵏ). Здесь xᵏ — текущая точка, αₖ — длина шага, а знак минус задаёт движение к уменьшению функции. Пример: спуск с горы по самому крутому склону.
Для понимания: Слишком малый шаг даёт медленное движение, слишком большой может перескочить минимум или вызвать расходимость.
Методы второго порядкаИспользуют градиент и вторые производные. Они учитывают не только направление спуска, но и кривизну функции.
Для понимания: Обычно быстрее около решения, но одна итерация вычислительно дороже и требует больше памяти.
Метод НьютонаИтерация: xᵏ⁺¹ = xᵏ − H⁻¹(xᵏ)∇f(xᵏ). Метод корректирует направление с учётом матрицы Гессе и для квадратичной функции может попасть в минимум за один шаг.
Для понимания: Ограничения: Гессе должен быть вычислим и пригоден для решения системы; вдали от минимума метод может работать нестабильно.
Пример проверки минимумаДля f(x)=(x−3)²: f′(x)=2(x−3), поэтому x=3. Затем f″(x)=2>0, значит это строгий минимум, а f(3)=0.
Для понимания: Каркас решения: найти производную → приравнять к нулю → проверить вторую производную → вычислить значение функции.
В этом разделе совпадений нет.

2.2. Выпуклое программирование и функция Лагранжа

Вопрос / терминОпределение, смысл и пример
Выпуклое множествоМножество, которое вместе с любыми двумя своими точками содержит весь отрезок между ними. Формально: θx+(1−θ)y ∈ C при 0≤θ≤1. Пример: круг и прямоугольник выпуклы, полумесяц — нет.
Для понимания: Выпуклость допустимой области означает отсутствие разрывов и «впадин» внутри неё.
Выпуклая функцияФункция, график которой лежит не выше хорды между любыми двумя его точками. Простая геометрическая форма — чаша. Пример: f(x)=x².
Для понимания: Для дважды дифференцируемой функции одной переменной признаком выпуклости служит f″(x)≥0 на всей области.
Строго выпуклая функцияВыпуклая функция, у которой хорда, кроме концов, проходит строго выше графика. Если минимум существует, он единственный.
Для понимания: Обычная выпуклая функция может иметь целый отрезок оптимальных точек, строго выпуклая — только одну.
Задача выпуклого программированияМинимизация выпуклой целевой функции на выпуклом множестве допустимых решений. Типичная запись: f₀(x)→min, fᵢ(x)≤0, Ax=b.
Для понимания: Неравенства задаются выпуклыми функциями, а равенства обычно должны быть аффинными, чтобы сохранялась выпуклость области.
Главное свойство выпуклой задачиЛюбой локальный минимум является глобальным. Поэтому найденная «ближайшая впадина» уже является наилучшим решением всей задачи.
Для понимания: Это главное отличие выпуклой оптимизации от общей нелинейной оптимизации с множеством локальных минимумов.
Условная оптимизацияПоиск минимума или максимума при дополнительных ограничениях. Пример: минимизировать стоимость рациона при заданном минимальном количестве белка и витаминов.
Для понимания: Ограничения описывают ресурсы, нормы, балансы и другие обязательные условия.
Ограничение-равенствоУсловие вида h(x)=0. Оно заставляет решение лежать на определённой линии, поверхности или гиперплоскости. Пример: x+y=2.
Для понимания: Переменные уже не могут изменяться свободно: они должны постоянно сохранять равенство.
Функция ЛагранжаВспомогательная функция, объединяющая цель и ограничения. Для одного равенства: L(x,λ)=f(x)+λh(x).
Для понимания: Вместо отдельного исследования цели и ограничения решают единую систему уравнений по исходным переменным и множителям.
Множитель ЛагранжаДополнительная переменная λ, которая связывает изменение целевой функции с ограничением. Геометрически она возникает из параллельности градиентов в точке касания.
Для понимания: В прикладных задачах множитель часто интерпретируют как приблизительную ценность дополнительной единицы ограниченного ресурса.
Геометрический смысл методаВ точке условного экстремума линия уровня цели касается границы допустимых решений. Поэтому ∇f(x*) = −λ∇h(x*): градиенты параллельны.
Для понимания: Если бы направления не совпадали, можно было бы немного сдвинуться вдоль ограничения и улучшить цель.
Алгоритм метода Лагранжа1) записать ограничение как h(x)=0; 2) построить L=f+λh; 3) взять производные по всем переменным и λ; 4) приравнять к нулю; 5) решить систему; 6) проверить тип точки.
Для понимания: Производная по λ возвращает исходное ограничение, поэтому его нельзя забывать.
Пример ЛагранжаМинимизировать x²+y² при x+y=2. L=x²+y²+λ(x+y−2). Из 2x+λ=0 и 2y+λ=0 получаем x=y, значит x=y=1, минимум равен 2.
Для понимания: Функция строго выпукла, а ограничение линейно, поэтому найденный минимум единственный и глобальный.
Ограничения-неравенстваУсловия вида gᵢ(x)≤0. Для них одного классического метода Лагранжа недостаточно: применяют условия Каруша — Куна — Таккера.
Для понимания: Неравенство может быть активным, когда выполняется как равенство, или неактивным, когда имеется запас.
Условия Каруша — Куна — ТаккераВключают стационарность, допустимость исходных ограничений, неотрицательность множителей и дополнительную нежёсткость λᵢgᵢ(x)=0.
Для понимания: Дополнение для понимания: в пункте программы прямо названа функция Лагранжа, но ККТ полезны для объяснения неравенств.
Дополнительная нежёсткостьУсловие λᵢgᵢ(x)=0. Если ограничение выполняется с запасом, его множитель равен нулю; если множитель положителен, ограничение активно.
Для понимания: Неактивный ресурс не ограничивает решение, поэтому небольшое его увеличение не меняет оптимум.
Ограничения методаРешение системы Лагранжа даёт кандидатов, но не всегда гарантирует минимум. Нужно проверить допустимость, вторые условия или выпуклость задачи.
Для понимания: При невыпуклой функции могут существовать несколько локальных экстремумов и седловые точки.
В этом разделе совпадений нет.

2.3. Линейное программирование и симплекс-метод

Вопрос / терминОпределение, смысл и пример
Линейное программированиеРаздел оптимизации, где целевая функция и все ограничения линейны. Пример: выбрать объёмы производства двух товаров для максимальной прибыли при ограниченных материалах.
Для понимания: Слово «программирование» здесь означает составление плана, а не написание компьютерного кода.
Общая постановкаТипичная задача: F=cᵀx→max или min при Ax≤b и x≥0. Вектор x содержит решения, c — их вклад в цель, b — запасы ресурсов.
Для понимания: Каждое ограничение описывает линейный баланс: расход ресурса не должен превысить его запас.
Целевая функцияЛинейная формула, значение которой нужно улучшить. Пример: F=300x₁+200x₂ — суммарная прибыль от двух товаров.
Для понимания: Коэффициент при переменной показывает, насколько изменится цель при увеличении этой переменной на единицу, если остальное неизменно.
Допустимый планНабор значений переменных, удовлетворяющий всем ограничениям и условиям неотрицательности.
Для понимания: Допустимый план может быть невыгодным, но он хотя бы физически или экономически возможен.
Оптимальный планДопустимый план, на котором целевая функция принимает наилучшее значение среди всех допустимых планов.
Для понимания: Сначала проверяется допустимость, только затем сравнивается качество решения.
Область допустимых решенийПересечение всех полупространств, заданных линейными ограничениями. Она является выпуклым многогранником.
Для понимания: Для двух переменных это многоугольник на плоскости, для большего числа — многомерный многогранник.
Почему оптимум ищут в вершинахЕсли конечный оптимум существует, хотя бы одно оптимальное решение линейной задачи находится в вершине допустимого многогранника.
Для понимания: Поэтому не нужно проверять бесконечно много внутренних точек: достаточно организовать переходы между вершинами.
Графический методДля двух переменных строят прямые ограничений, выбирают нужные полуплоскости, находят их пересечение и проверяют вершины допустимой области.
Для понимания: Метод нагляден, но для трёх и более переменных становится неудобным или невозможным для визуализации.
Каноническая формаФорма, в которой ограничения представлены равенствами, а переменные неотрицательны. Неравенство x₁+x₂≤4 превращают в x₁+x₂+s₁=4.
Для понимания: Дополнительная переменная s₁ показывает неиспользованный остаток ресурса.
БазисНабор переменных, через которые выражается текущий план. Число базисных переменных обычно равно числу линейно независимых ограничений-равенств.
Для понимания: Небазисные переменные временно полагают равными нулю, а базисные находят из системы.
Опорный планДопустимый базисный план. Геометрически он соответствует вершине допустимого многогранника.
Для понимания: Симплекс-метод не перебирает произвольные точки, а движется именно от одного опорного плана к соседнему.
Идея симплекс-методаПоследовательно переходить между соседними вершинами, каждый раз улучшая или не ухудшая целевую функцию, пока дальнейшее улучшение невозможно.
Для понимания: Это организованный перебор небольшого числа перспективных вершин вместо проверки всех возможных решений.
Начальный базисЕсли дополнительные переменные образуют единичную матрицу, они могут стать начальным базисом. Тогда исходные переменные равны нулю, а дополнительные — запасам ресурсов.
Для понимания: Если естественного базиса нет, используют искусственные переменные и метод искусственного базиса.
Входящая переменнаяНебазисная переменная, увеличение которой способно улучшить целевую функцию. Она выбирается по оценкам в строке цели.
Для понимания: Конкретный знак выбора зависит от принятой записи симплекс-таблицы, поэтому на экзамене важнее объяснить смысл — улучшение цели.
Выходящая переменнаяБазисная переменная, которая первой станет нулевой при увеличении входящей. Её находят правилом минимального положительного отношения.
Для понимания: Это правило не даёт перейти через границу допустимой области и получить отрицательную базисную переменную.
Симплекс-итерацияВыбрать входящую переменную → по отношениям выбрать выходящую → выполнить разрешающее преобразование → получить новый базисный допустимый план.
Для понимания: После каждой итерации меняется одна базисная переменная и происходит переход в соседнюю вершину.
Критерий оптимальностиВ строке целевой функции не остаётся коэффициентов, показывающих возможность дальнейшего улучшения. Тогда текущий опорный план оптимален.
Для понимания: Знак коэффициентов зависит от формы таблицы, поэтому лучше говорить о невозможности улучшить цель.
Метод искусственного базисаПрименяется, когда начальный допустимый базис нельзя получить из обычных дополнительных переменных. Временно вводят искусственные переменные и добиваются их удаления.
Для понимания: Если искусственную переменную невозможно вывести и она остаётся положительной, исходная система ограничений несовместна.
Неограниченная задачаСуществуют допустимые направления, по которым целевую функцию можно улучшать без предела. Конечного оптимального значения нет.
Для понимания: В симплекс-таблице это проявляется, когда выбранную переменную можно увеличивать, но правило отношений не даёт выходящей переменной.
Несовместная задачаНет ни одного набора переменных, удовлетворяющего всем ограничениям одновременно.
Для понимания: Пример: одновременно потребовать x≥5 и x≤3.
Вырожденный планОпорный план, в котором хотя бы одна базисная переменная равна нулю. Возможны шаги без улучшения целевой функции.
Для понимания: В редких случаях вырожденность может привести к зацикливанию, поэтому применяют специальные правила выбора.
Простой примерМаксимизировать F=3x₁+2x₂ при x₁+x₂≤4, x₁≤2, x₂≤3. Лучшая вершина — (2,2), где F=10.
Для понимания: Симплекс может пройти по вершинам (0,0)→(2,0)→(2,2), постоянно улучшая прибыль.
В этом разделе совпадений нет.

2.4. Оптимизация на графах, вариационное исчисление и уравнение Эйлера

Вопрос / терминОпределение, смысл и пример
Оптимизация на графахПоиск лучшего пути, дерева, потока или набора рёбер в системе, представленной графом. Пример: построить самый быстрый маршрут между складами.
Для понимания: Графовая модель удобна, когда задача состоит из объектов и связей между ними.
Взвешенный графГраф, в котором каждому ребру назначен вес: расстояние, время, цена, риск или пропускная способность.
Для понимания: Смысл веса определяется задачей: минимизируют стоимость или расстояние, а пропускную способность обычно максимизируют.
Стоимость путиСумма весов рёбер, входящих в путь: W(P)=Σ w(e). Пример: маршрут из трёх дорог длиной 2, 5 и 1 км имеет стоимость 8 км.
Для понимания: Кратчайший путь — путь с минимальной суммарной стоимостью, а не обязательно с минимальным числом рёбер.
Кратчайший путьПуть между заданными вершинами с минимальной суммой весов. Применяется в навигации, маршрутизации пакетов и планировании действий.
Для понимания: Если все рёбра имеют одинаковый вес, можно использовать поиск в ширину; при разных неотрицательных весах — Дейкстру.
Алгоритм ДейкстрыНаходит кратчайшие пути от одной исходной вершины при неотрицательных весах. На каждом шаге фиксирует вершину с минимальной текущей оценкой и улучшает оценки её соседей.
Для понимания: После фиксации расстояние считается окончательным, поэтому отрицательные рёбра нарушают логику алгоритма.
РелаксацияПроверка, можно ли улучшить путь до вершины v через вершину u: если d(u)+w(u,v)<d(v), значение d(v) заменяется.
Для понимания: Релаксация — главный повторяющийся шаг большинства алгоритмов кратчайших путей.
Сложность ДейкстрыПри списках смежности и бинарной куче: O((V+E) log V), память — O(V+E) вместе с графом.
Для понимания: V — число вершин, E — число рёбер; куча ускоряет выбор вершины с минимальной оценкой.
Минимальное остовное деревоНабор рёбер, соединяющий все вершины связного неориентированного графа без циклов и с минимальным общим весом. Алгоритмы: Прим и Краскал.
Для понимания: Пример: соединить все офисы кабелем с минимальной общей длиной.
Кратчайший путь и остовКратчайший путь оптимизирует маршрут между выбранными вершинами. Остов должен соединить все вершины, и расстояния между отдельными парами в нём могут быть не минимальными.
Для понимания: Дейкстра не строит минимальный остов, а Прим и Краскал не решают задачу кратчайшего пути.
Максимальный потокПоиск максимального объёма, который можно передать от истока к стоку при ограниченных пропускных способностях рёбер. Пример: максимальный поток данных через сеть.
Для понимания: Поток ограничен пропускными способностями и должен сохраняться в промежуточных вершинах.
Задача коммивояжёраНайти минимальный замкнутый маршрут, который посещает каждую вершину ровно один раз и возвращается в начало.
Для понимания: Задача вычислительно трудна: полный перебор растёт факториально, поэтому используют ветви и границы, эвристики и приближения.
Вариационное исчислениеРаздел оптимизации, где неизвестным является не число или конечный вектор, а целая функция. Пример: найти форму траектории с минимальными затратами энергии.
Для понимания: Обычная оптимизация выбирает точку, вариационное исчисление выбирает кривую или функцию.
ФункционалОтображение, которое каждой допустимой функции ставит в соответствие число. Пример: J[y]=∫(y′)²dx оценивает функцию через интеграл квадрата её производной.
Для понимания: Функция принимает число и возвращает число; функционал принимает целую функцию и возвращает число.
Простейшая вариационная задачаНайти функцию y(x), минимизирующую J[y]=∫ₐᵇ F(x,y,y′)dx, при фиксированных условиях y(a)=A и y(b)=B.
Для понимания: Подынтегральная функция F зависит от точки, значения искомой функции и её производной.
ЭкстремальФункция, удовлетворяющая необходимому условию экстремума функционала. Она является кандидатом на минимум или максимум.
Для понимания: Как стационарная точка в обычной оптимизации, экстремаль ещё не всегда гарантирует именно минимум.
Вариация функцииМалое допустимое изменение yε(x)=y(x)+εη(x), где η(a)=η(b)=0, чтобы сохранить граничные значения.
Для понимания: Сравнивают функционал на исходной и немного изменённой функции и требуют, чтобы первая вариация была равна нулю.
Уравнение ЭйлераНеобходимое условие экстремума: ∂F/∂y − d/dx(∂F/∂y′)=0. Оно превращает поиск оптимальной функции в решение дифференциального уравнения.
Для понимания: Уравнение Эйлера — аналог условия нулевой производной, но для пространства функций.
Пример уравнения ЭйлераДля J[y]=∫₀¹(y′)²dx имеем F=(y′)². Тогда ∂F/∂y=0, ∂F/∂y′=2y′, поэтому y″=0. При y(0)=0, y(1)=1 получаем y=x.
Для понимания: Оптимальная кривая оказалась прямой: равномерное изменение даёт минимальное значение данного функционала.
Ограничение уравнения ЭйлераЭто необходимое, но не всегда достаточное условие минимума. Требуются гладкость функций и иногда дополнительная проверка второй вариации или выпуклости.
Для понимания: Полученное дифференциальное уравнение также может быть трудно решить аналитически.
В этом разделе совпадений нет.

3.1. Исследование операций, системный анализ и теория выбора

Вопрос / терминОпределение, смысл и пример
Исследование операцийНаучный подход к обоснованию решений с помощью математических моделей, оптимизации, вероятности и вычислений. Пример: распределить машины по маршрутам так, чтобы суммарные затраты были минимальными.
Для понимания: Главная цель — не просто описать систему, а сравнить варианты и количественно выбрать лучший.
ОперацияУправляемый процесс, направленный на достижение определённой цели. Это может быть производство, перевозка, обслуживание заявок или распределение ресурсов.
Для понимания: Операция включает участников, ресурсы, условия, решения и измеримый результат.
Системный анализМетодология исследования сложной проблемы как целостной системы: выясняются цель, элементы, связи, внешняя среда, ограничения и последствия решений.
Для понимания: Он начинается раньше оптимизации: сначала нужно правильно понять проблему и только потом строить математическую модель.
Исследование операций и системный анализИсследование операций обычно сосредоточено на количественном выборе оптимального решения. Системный анализ шире и охватывает постановку проблемы, структуру системы и согласование целей.
Для понимания: Просто: системный анализ отвечает «что за проблема и как устроена система», исследование операций — «какой вариант математически лучше».
Лицо, принимающее решениеЧеловек, группа или организация, которые выбирают альтернативу и несут ответственность за последствия.
Для понимания: Предпочтения и допустимый риск зависят от конкретного лица, поэтому одинаковые данные могут привести к разным решениям.
АльтернативаОдин из допустимых вариантов действия. Пример: купить собственный сервер, арендовать облако или модернизировать текущий.
Для понимания: Альтернативы должны быть реально выполнимыми и различимыми по результатам.
Состояние внешней средыУсловие, не полностью контролируемое принимающим решение, но влияющее на результат. Пример: высокий, средний или низкий спрос.
Для понимания: При выборе решение зависит не только от альтернативы, но и от того, какое состояние среды наступит.
Последствие решенияРезультат сочетания выбранной альтернативы и состояния среды: прибыль, затраты, время, качество или риск.
Для понимания: Обычно последствия записывают в матрице решений, где строки — альтернативы, столбцы — состояния.
КритерийПоказатель, по которому оцениваются и сравниваются варианты. Пример: цена, скорость, надёжность, безопасность.
Для понимания: Критерий должен быть связан с целью и позволять отличить более предпочтительное решение от менее предпочтительного.
Отношение предпочтенияЗапись x ≻ y означает, что альтернатива x предпочтительнее y для данного лица.
Для понимания: Отношение не обязательно основано только на одном числе: оно может учитывать набор критериев и субъективные приоритеты.
Отношение безразличияЗапись x ~ y означает, что принимающее решение считает варианты равноценными.
Для понимания: Равноценность не требует полного совпадения характеристик: преимущества по разным критериям могут компенсировать друг друга.
Полнота предпочтенийДля любых двух альтернатив лицо может сказать: первая лучше, вторая лучше или они равноценны.
Для понимания: Если варианты невозможно сравнить, отношение предпочтения неполно, что часто встречается в многокритериальных задачах.
Транзитивность предпочтенийЕсли x ≻ y и y ≻ z, то должно выполняться x ≻ z.
Для понимания: Транзитивность нужна для непротиворечивого выбора; иначе предпочтения образуют цикл.
Функция выбораПравило, которое из каждого допустимого множества альтернатив X выделяет выбранное подмножество C(X)⊆X.
Для понимания: Она описывает сам результат выбора, даже если предпочтения не выражены одной числовой формулой.
Функция полезностиЧисловая функция u(x), представляющая предпочтения: если u(x)>u(y), то x предпочтительнее y.
Для понимания: Полезность — не обязательно деньги; это числовое отражение ценности с учётом удобства, риска и других факторов.
Задача выбораНужно из множества допустимых альтернатив выбрать одну или несколько наиболее предпочтительных по заданным критериям и правилам.
Для понимания: Выбор может быть оптимизацией одного критерия, ранжированием или выделением Парето-множества.
Этапы принятия решенияПоставить проблему → определить цель → сформировать альтернативы → задать критерии и ограничения → оценить последствия → сравнить варианты → выбрать → проверить результат.
Для понимания: Ошибка на раннем этапе, например неверная цель, не исправляется даже идеальным математическим методом.
Однокритериальный выборВсе альтернативы сравниваются по одному показателю. Пример: выбрать тариф с минимальной ценой при одинаковых остальных условиях.
Для понимания: Если критерий один и числовой, задача часто сводится к обычной скалярной оптимизации.
Многокритериальный выборОдновременно учитываются несколько показателей, которые могут конфликтовать. Пример: выбрать ноутбук по цене, производительности и времени работы.
Для понимания: Универсально лучшего варианта может не быть, поэтому применяют Парето-оптимальность и схемы компромисса.
В этом разделе совпадений нет.

3.2. Детерминированные, стохастические задачи и решения при неопределённости

Вопрос / терминОпределение, смысл и пример
Детерминированная задачаЗадача, где все существенные параметры и последствия решений известны точно. Одному набору управляющих переменных соответствует определённый результат.
Для понимания: Пример: известны цены, запасы ресурсов и нормы расхода, поэтому прибыль производственного плана вычисляется однозначно.
Стохастическая задачаЗадача, в которой хотя бы некоторые параметры случайны и описываются вероятностями или распределениями. Решение оценивается с учётом возможных исходов.
Для понимания: Пример: магазин выбирает запас товара, а будущий спрос является случайной величиной.
ОпределённостьСитуация, когда известны все условия и результат каждой альтернативы. Выбор сводится к прямому сравнению значений критерия.
Для понимания: Например, два фиксированных маршрута с заранее известной стоимостью и временем.
РискСитуация, когда известны возможные состояния среды и можно указать их вероятности. Результат конкретного решения заранее не известен, но его распределение можно оценить.
Для понимания: Пример: доход проекта зависит от высокого или низкого спроса, вероятности которых оценены по статистике.
НеопределённостьСитуация, когда возможные состояния могут быть известны, но надёжные вероятности отсутствуют. Поэтому ожидаемое значение посчитать обоснованно нельзя.
Для понимания: Пример: запуск совершенно нового продукта на рынке без подходящей статистики.
Риск и неопределённостьПри риске вероятности состояний известны или оценены; при неопределённости вероятности неизвестны или недостоверны.
Для понимания: Это главное различие, которое нужно назвать на экзамене.
Матрица решенийТаблица, где строки соответствуют альтернативам, столбцы — состояниям среды, а ячейки — выигрышам или потерям.
Для понимания: Матрица позволяет применять единые критерии Вальда, Сэвиджа, Гурвица и Лапласа.
Ожидаемый выигрышПри известных вероятностях для альтернативы i вычисляют Eᵢ=Σ pⱼaᵢⱼ, где pⱼ — вероятность состояния, aᵢⱼ — результат.
Для понимания: Выбирают максимальное ожидание для выигрышей или минимальное — для затрат.
Пример ожидаемого выигрышаЕсли прибыль 100 тыс. с вероятностью 0,7 и 20 тыс. с вероятностью 0,3, то E=0,7·100+0,3·20=76 тыс.
Для понимания: Ожидаемое значение — средний результат большого числа аналогичных решений, а не гарантированная прибыль одного проекта.
Отношение к рискуРиск-нейтральное лицо ориентируется на математическое ожидание; осторожное предпочитает более надёжный результат; склонное к риску может выбрать высокий потенциальный выигрыш.
Для понимания: Два человека могут рационально выбрать разные варианты при одинаковой матрице результатов.
Критерий ВальдаКрайне осторожный критерий. Для каждой альтернативы находят худший результат, затем выбирают лучший из этих худших результатов — принцип максимина.
Для понимания: Подходит, когда ошибка особенно опасна и принимающий решение не доверяет благоприятным сценариям.
Критерий максимаксаКрайне оптимистичный подход: для каждой альтернативы берут лучший возможный результат и выбирают наибольший из них.
Для понимания: Он ориентирован на шанс максимального выигрыша и почти не учитывает неблагоприятные исходы.
Критерий ЛапласаЕсли нет оснований считать состояния более или менее вероятными, им назначают равные вероятности и сравнивают средние результаты.
Для понимания: Принцип недостаточного основания: раз информации нет, состояния считаются равноправными.
Критерий ГурвицаКомпромисс оптимизма и пессимизма: учитываются лучший и худший результаты с коэффициентом оптимизма α.
Для понимания: При α, близком к 1, решение более оптимистично; при близком к 0 — более осторожно.
Критерий СэвиджаМинимизирует максимальное сожаление — потерю относительно лучшего решения, которое можно было бы выбрать после знания состояния среды.
Для понимания: Сначала строят матрицу сожалений: из лучшего результата каждого столбца вычитают результат альтернативы.
Как выбрать критерийКритерий определяется отношением к риску и ценой ошибки. Вальд — осторожность, максимакс — оптимизм, Гурвиц — компромисс, Сэвидж — защита от сильного сожаления.
Для понимания: Нельзя утверждать, что один критерий всегда правильный: они выражают разные предпочтения.
В этом разделе совпадений нет.

3.3. Классификация задач оптимизации

Вопрос / терминОпределение, смысл и пример
Скалярная оптимизацияЗадача с одной числовой целевой функцией. Пример: минимизировать стоимость, время или ошибку.
Для понимания: Даже если переменных много, задача остаётся скалярной, пока итоговый критерий один.
Линейная задачаЦелевая функция и все ограничения являются линейными выражениями. Решается симплекс-методом или методами внутренней точки.
Для понимания: Пример: прибыль — сумма прибылей по товарам, а расходы ресурсов пропорциональны объёму выпуска.
Нелинейная задачаЦель или хотя бы одно ограничение содержит нелинейность: квадрат, произведение переменных, дробь, степень, логарифм и так далее.
Для понимания: Нелинейные задачи могут иметь несколько локальных минимумов и требуют градиентных, ньютоновских или специальных методов.
Непрерывная задачаПеременные могут принимать любые вещественные значения из допустимого диапазона. Пример: объём сырья может быть 2,35 тонны.
Для понимания: Для непрерывных переменных применим аппарат производных и гладкой оптимизации.
Дискретная задачаПеременные принимают значения из конечного или счётного множества. Пример: выбрать конкретный маршрут или число машин.
Для понимания: Между допустимыми значениями могут быть разрывы, поэтому обычный градиент не определяет переход между решениями.
Целочисленное программированиеДискретная задача, где часть или все переменные обязаны быть целыми. Пример: нельзя приобрести 2,4 автобуса.
Для понимания: Линейная целевая функция с целочисленными переменными уже не решается простым округлением линейного решения.
Бинарная переменнаяПеременная, принимающая только 0 или 1. Она кодирует решение «нет/да»: открыть склад, выбрать проект, назначить сотрудника.
Для понимания: Бинарные переменные позволяют математически описывать логические условия и выбор вариантов.
Комбинаторная оптимизацияПоиск лучшего объекта среди большого конечного множества комбинаций: маршрутов, подмножеств, расписаний или назначений.
Для понимания: Число вариантов часто растёт экспоненциально или факториально, поэтому полный перебор быстро становится невозможным.
Многокритериальная задачаОдновременно оптимизируется вектор критериев (f₁(x),…,fₖ(x)). Критерии могут конфликтовать.
Для понимания: Пример: автомобиль должен быть дешёвым, безопасным и экономичным, но улучшение одного свойства может ухудшать другое.
Почему нет одного очевидного оптимумаОдна альтернатива может быть лучше по цене, другая — по качеству. Без дополнительных предпочтений нельзя однозначно сказать, какая из них лучшая.
Для понимания: Поэтому сначала исключают доминируемые решения, а затем выбирают компромисс среди Парето-множества.
Свёртка критериевПреобразование нескольких критериев в один, например взвешенной суммой F=Σwᵢfᵢ.
Для понимания: Вес показывает важность критерия, но требует сопоставимых масштабов или предварительной нормализации.
Смешанная классификацияКлассы не исключают друг друга. Одна задача может одновременно быть нелинейной, дискретной, стохастической и многокритериальной.
Для понимания: Например, выбор портфеля проектов с бюджетом, случайной прибылью и критериями доходности и риска.
Линейная и нелинейнаяРазличаются формой цели и ограничений. Линейная структура даёт выпуклый многогранник и специализированные методы; нелинейная требует исследования производных и формы функции.
Для понимания: Квадрат переменной уже делает задачу нелинейной, даже если остальные выражения линейны.
Непрерывная и дискретнаяВ непрерывной задаче допустимы промежуточные значения; в дискретной — только отдельные варианты. Пример: масса материала непрерывна, число работников дискретно.
Для понимания: Дискретная задача часто решается ветвями и границами, динамическим программированием или эвристиками.
В этом разделе совпадений нет.

3.4. Парето-оптимальность, компромиссы, динамические и марковские модели

Вопрос / терминОпределение, смысл и пример
ДоминированиеРешение x доминирует y, если оно не хуже по всем критериям и строго лучше хотя бы по одному.
Для понимания: Доминируемое решение можно исключить без знания точных весов критериев: существует явно более выгодная альтернатива.
Парето-оптимальное решениеРешение, которое невозможно улучшить по одному критерию, не ухудшив хотя бы один другой. Оно также называется недоминируемым.
Для понимания: Парето-оптимальность означает отсутствие очевидно лучшего решения, но не означает абсолютное превосходство над всеми.
Фронт ПаретоСовокупность всех Парето-оптимальных решений. На графике двух критериев это граница достижимых компромиссов.
Для понимания: После построения фронта принимающий решение выбирает вариант с учётом собственных приоритетов.
Пример ПаретоТелефон A дешевле, а телефон B мощнее. Если нет телефона одновременно дешевле A и мощнее A, то A может быть Парето-оптимальным.
Для понимания: Несколько Парето-решений могут быть равно рациональными, но предназначенными для разных предпочтений.
Ограничение Парето-подходаОн отсеивает доминируемые варианты, но обычно не выбирает единственное решение. Нужна дополнительная схема компромисса.
Для понимания: Парето отвечает «какие варианты разумны», а не «какой из них выбрать конкретному человеку».
Взвешенная суммаКритерии объединяют в одну функцию: F(x)=w₁f₁(x)+…+wₖfₖ(x). Чем больше вес, тем важнее критерий.
Для понимания: Перед сложением критерии часто нормируют, иначе критерий с крупными числовыми значениями будет искусственно доминировать.
Метод главного критерияОдин критерий оптимизируют, а остальные переводят в ограничения. Пример: минимизировать цену при надёжности не ниже 99,9%.
Для понимания: Подходит, когда имеется главный показатель и понятны минимально допустимые уровни остальных.
Метод последовательных уступокСначала оптимизируют самый важный критерий, затем разрешают его небольшое ухудшение и улучшают следующий критерий.
Для понимания: Величина уступки показывает, чем готовы пожертвовать ради улучшения следующего показателя.
Метод идеальной точкиСначала формируют воображаемую точку с лучшими значениями каждого критерия, затем выбирают реальное решение, наиболее близкое к ней.
Для понимания: Идеальная точка обычно недостижима одновременно, но служит ориентиром для компромисса.
Динамическая задачаЗадача, где решения принимаются последовательно по этапам, а текущее действие изменяет будущие возможности и состояния системы.
Для понимания: Пример: предприятие каждый месяц решает объём производства, учитывая текущий склад и будущий спрос.
Состояние системыМинимальный набор информации, достаточный для выбора следующего действия и описания дальнейшего развития. Пример: текущий запас товара.
Для понимания: Правильно выбранное состояние должно содержать всё важное из прошлого, не сохраняя лишнюю историю.
Управление или действиеРешение, принимаемое на текущем этапе. Оно изменяет состояние и приносит выигрыш или затраты.
Для понимания: Пример: произвести 100 единиц, заказать сырьё или остановить оборудование.
Принцип оптимальности БеллманаКаково бы ни было первое решение, оставшаяся часть оптимальной стратегии должна быть оптимальной для состояния, возникшего после этого решения.
Для понимания: Это логическая основа динамического программирования и рекуррентных уравнений Беллмана.
Динамическое программированиеМетод, разбивающий многоэтапную задачу на взаимосвязанные подзадачи по состояниям и этапам. Результаты подзадач сохраняются и используются повторно.
Для понимания: Вместо перебора всех последовательностей решений вычисляют лучшие продолжения для отдельных состояний.
Марковское свойствоПри известном текущем состоянии распределение будущего не зависит от всей прошлой истории. Прошлое влияет на будущее только через текущее состояние.
Для понимания: Это не означает, что прошлое неважно; важная информация из прошлого уже должна быть включена в состояние.
Марковская модель принятия решенийМодель последовательного выбора со множеством состояний, действий, вероятностей переходов, вознаграждений и стратегией управления.
Для понимания: Она применяется, когда действие не полностью определяет следующее состояние, а задаёт вероятности возможных переходов.
Вероятность переходаВеличина P(s′|s,a), показывающая вероятность попасть в состояние s′ из состояния s после действия a.
Для понимания: Для каждого состояния и действия суммы вероятностей всех возможных следующих состояний равны единице.
ВознаграждениеЧисловой результат действия или перехода: прибыль, полезность, штраф или затраты.
Для понимания: Затраты можно записывать отрицательной наградой; цель — максимизировать ожидаемую суммарную награду.
ПолитикаПравило, определяющее, какое действие выбирать в каждом состоянии. Политика может быть детерминированной или вероятностной.
Для понимания: Решением марковской задачи является не одно действие, а стратегия для всех возможных состояний.
ДисконтированиеКоэффициент γ от 0 до 1, уменьшающий вес отдалённых наград. Чем меньше γ, тем важнее ближайший результат.
Для понимания: Дополнение для понимания: помогает учитывать временную ценность результата и ограничивать бесконечную сумму наград.
Уравнение БеллманаЦенность состояния равна лучшему сочетанию текущей награды и ожидаемой ценности следующего состояния: идея «сегодняшний результат + оптимальное будущее».
Для понимания: Уравнение связывает глобальную оптимальную стратегию с локальным выбором на каждом шаге.
Решения при неопределённостиКогда вероятности состояний неизвестны, используют критерии Вальда, Лапласа, Гурвица и Сэвиджа.
Для понимания: Не путай: Парето решает конфликт нескольких критериев, а эти критерии — выбор при неизвестном состоянии среды.
В этом разделе совпадений нет.

Основа: актуальные пункты 2.1–2.4 и 3.1–3.4 программы вступительного испытания. Дополнительные пояснения включены только там, где они помогают восстановить смысл ответа; условия ККТ и дисконтирование отдельно помечены как дополнение для понимания.
